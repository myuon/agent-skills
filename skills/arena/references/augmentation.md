# データの系列を増やす(疑似世界と時間の窓)

実データは1本の歴史しかない。新しいデータが溜まるのを待つと、ループが止まる。そこで、今あるデータから「別の世界」と「別の時期」を作り、どの世界・どの時期でも勝つかを採点に入れる。目的は、少数の対象や1つの局面への依存を見抜くこと。

作るときの条件は、**元のデータの複雑さ(ボラティリティ、流動性、対象どうしの相関、日中の形)を壊さないこと**。単純なノイズを足すと、現実に無い簡単な世界ができて、意味のない勝ちが増える。

## 疑似世界の作り方

株の日次戦略で使った例。世界の定義は seed とハッシュつきのデータとして固定し、ループから変えられないようにする。

| 世界 | 作り方 | 見抜けること |
| --- | --- | --- |
| W0 原本 | そのまま | 参照 |
| W1 部分集合 | 対象の 50% を残す。業種 × 流動性の三分位で層化し、seed を変えて数通り | 特定の対象の組への依存 |
| W2 勝ち対象を外す | 期間中の値上がり上位 3・5 を除く | 少数の大当たりへの依存 |
| W3 偽の対象を足す | 全体の 30% 程度を足す。半分は実在の対象の日次変化・日中の形・出来高を数日のブロックでブートストラップしたもの(ボラと流動性は保たれ、トレンドの構造は壊れる)。残り半分は、同じ業種の 2〜3 対象を毎日等ウェイトで混ぜた混合の対象 | 「たまたま上がった」対象への反応、見かけの特徴への過適合 |

マーケットメイクのように対象が少ない題材では、次が使える。
- 1つの銘柄(ペア)を抜いて学習し、抜いた銘柄で評価する(leave-one-group-out)
- 別の市場・別の取引所のデータで、同じ候補を確かめる

## 時間の窓

- 設計用の期間を、短い窓(例: 3か月を毎月ずらして9本)と、いくつかの区間(前・中・後)に分ける
- 各窓は同じ初期条件(現金だけ)から始める。履歴の特徴量は、窓の始まりより前のデータで暖機する
- 門の例: 9本中6本以上で基準線に勝つ、最悪の窓でも基準線比 −5% 以上、最新の区間で勝つ

## 組み合わせの交差検証(CPCV)

データを等しい量のブロック(例: 6個)に分け、ブロック2個の全組み合わせを評価に、残りを学習に使う。評価ブロックの前後には空白(purge と embargo)を置く。
- 候補と基準を各組み合わせで学習し直し、「勝つ組み合わせの割合」を門にする
- 新しいデータを待たずに、多数の「別の分け方」で確かめられる
- PBO(過学習の確率)はブロックが少ないと雑音が大きい。報告だけにする

## 採点への入れ方

- **主スコアは世界の中央値**にする。下位の値(最悪の世界や下位25%)を主スコアにすると、リスクをまったく取らない戦略が有利になり、勝てなくなる
- **最悪の世界は床の門にする**。例: 全世界の 70% 以上で基準線に勝ち、下位 25% の世界でも基準線との差が正
- 比べる相手は、**同じ世界で走らせた基準線**にする。市場全体の上昇に乗っただけの成績を割り引ける
- リスクは、主スコアを削らず、最大下落の上限のような硬い制約で管理する
- 評価が重くなるので、2段にする。ループは速い版(原本 + 部分集合2つ + 勝ち対象を外す1つ + 窓)で回し、見込みのあるものだけ完全版で採点する。完全版を通ったものだけを採用として記録する
- 疑似世界での評価も、試行回数に数える

## 限界(必ず契約に書く)

- 疑似世界は、新しい局面(レジーム)を作らない。どれも同じ期間の組み替えにすぎない。局面の変化への頑健性は、検証・封印テスト・長い期間のデータでしか分からない
- 世界どうしは独立ではない(同じ期間の同じ値動きから作っている)。「12世界すべてで勝った」を12回の独立な勝ちと読まない。有意性の検定には使わず、崩れ方の検出(足切り)に使う
- 偽の対象は目立つことがある。混合の対象は売買代金が合計になって流動性の上位に入りやすく、保有の3〜4割を占めた例がある。ブートストラップした対象は元の平均的な上昇を受け継ぐので、偽の対象を足した世界では全員の成績が上振れしやすい。その世界は大きさを見ず、符号(基準線に勝つか)だけを見る
- 強い傾向の期間では、候補がみな全世界で勝ってしまい、ふるい分けにならないことがある。そのときは中央値や最悪値の「余裕」の大きさで比べ、局面の違う検証に頼る
- 偽の対象を作るときに、検証期間や封印期間のデータを使わない(暖機の履歴に使うだけでも、境界を確認する)
